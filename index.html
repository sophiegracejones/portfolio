Vending Machine FSM — FPGA Implementation

Used one-hot encoding across 10 D flip-flops, derived all state-transition and output equations by hand, then implemented and verified the full design on a DE-10 Lite FPGA — routing coin inputs, LED indicators, and a two-digit seven-segment display through a Quartus block schematic.

MATLAB · DSP · Signal Processing

Text-Dependent Speaker Recognition

93.3%Overall accuracy
20Speakers
60Test files

Built a speaker identification system in MATLAB using Mel-Frequency Cepstral Coefficients (MFCCs). Extracted 13-coefficient MFCC feature vectors from audio recordings, trained per-speaker centroid models on 3 recordings each, and classified unknown speakers by Euclidean distance. Achieved 93.3% accuracy across 4 datasets (20 speakers, 60 test files) — with one dataset reaching 100%. Error analysis revealed that all misclassifications occurred between acoustically similar speaker pairs with narrow score margins, and that synthetic voices were trivially separable (scores 5–10× further from human models).
